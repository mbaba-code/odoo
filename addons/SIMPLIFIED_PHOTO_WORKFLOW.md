# Nouveau Workflow Simplifié des Photos - Guide Concierge

## 🎯 Objectif

**Avant:** Uploader les photos 3 fois (propriété, unité, réservation) = perte de temps énorme ❌

**Maintenant:** Uploader une fois → Copie automatique = workflow super rapide ✅

---

## 📸 Nouveau Workflow Simplifié

### Étape 1: Ajouter les photos à L'UNITÉ (une seule fois!)

```
1. Ouvrir l'unité
2. Aller à l'onglet "🖼️ Galerie complète de photos"
3. Dans la section "Gérer les photos":
   ├─ Cliquer sur le bouton "+" pour ajouter une photo
   ├─ Uploader l'image (JPG/PNG)
   ├─ Donner un titre descriptif:
   │  ├─ "Chambre principale"
   │  ├─ "Salle de bain"
   │  ├─ "Cuisine"
   │  ├─ "Salon"
   │  └─ "Balcon"
   ├─ Cocher "📌" si c'est la meilleure photo (couverture)
   └─ Drag-drop pour réorganiser l'ordre
```

**Résultat:** Les photos sont maintenant dans l'unité. C'est fini ici!

---

### Étape 2: Créer une Réservation

```
1. Créer une nouvelle réservation
2. Sélectionner l'unité
3. Entrer les dates et client
4. Sauvegarder
5. Aller à l'onglet "📸 Galerie complète d'inspection"
6. Cliquer sur le bouton "📋 Copier photos de l'unité"
```

**Résultat:** ✨ AUTOMATIQUE! Les photos de l'unité apparaissent comme "check-in"!

## 📋 Types de Photos dans une Réservation

Quand vous travaillez avec les photos de réservation:

```
check_in  → 📸 Photos à L'ARRIVÉE du client
           Copiées automatiquement de l'unité
           Montre l'état initial

check_out → 📸 Photos AU DÉPART du client
           À ajouter manuellement
           Montre l'état final / nettoyage

damage    → 🚨 Photos de DÉGÂTS/PROBLÈMES
           À ajouter si vous découvrez des dégâts
           Documentation pour sinistre

other     → 📷 Autres photos
           Évidence supplémentaire si nécessaire
```

### Comment Changer le Type?

```
1. Dans la liste "Gérer les photos"
2. Cliquer sur la colonne "Type"
3. Sélectionner dans le menu:
   ├─ Arrivée (Check-in) ← Défaut
   ├─ Départ (Check-out)
   ├─ Dégâts/Problèmes
   └─ Autre
4. Automatiquement sauvegardé!
```

## ⚡ Conseil: Workflow Complet Check-In/Check-Out

### À L'ARRIVÉE du Client (Check-in):

```
✓ 1. La réservation a déjà les photos de l'unité (check_in)
✓ 2. Comparer: Photos de la réservation vs état actuel
✓ 3. Si dégâts détectés: Ajouter photos type "damage"
✓ 4. Prendre photos supplémentaires si besoin
✓ 5. Valider que tout est bon → Accueillir le client!
```

### AU DÉPART du Client (Check-out):

```
✓ 1. Accéder à la même réservation
✓ 2. Ajouter photos "check_out" de l'état final
✓ 3. Comparer avec check_in pour identifier dégâts
✓ 4. Documenter nettoyage → Avant/Après photos
✓ 5. Sauvegarder les dégâts si nécessaire
```

### Exemple Réel:

```
RÉSERVATION: Chambre 2 | 20-25 Nov | Jean Dupont

Galerie:
├─ Chambre - Check-in        → Uploadée auto
├─ Salle de bain - Check-in  → Uploadée auto
├─ Cuisine - Check-in        → Uploadée auto
├─ Salon - Check-in          → Uploadée auto
├─ Coin café cassé - Damage  ← Ajoutée au check-in
├─ Chambre - Check-out       ← Ajoutée au départ
├─ Salle de bain - Check-out ← Ajoutée au départ
├─ Cuisine - Check-out       ← Ajoutée au départ
├─ Canapé tâche - Damage     ← Dégât détecté
└─ Salle de bain après nettoyage - Check-out
```

## 💡 Astuces pour les Concierges

### 1. Optimiser les Photos de l'Unité

```
✓ Bonnes pratiques:
  ├─ Prendre au minimum 5-6 photos
  ├─ Bien éclairer (lumière naturelle)
  ├─ Montrer l'état SANS aucun dégât
  ├─ Couvrir tous les espaces (chambre, salle, cuisine, etc.)
  ├─ Cocher "📌 Couverture" pour la MEILLEURE photo
  └─ Donner des titres clairs et en français

❌ À éviter:
  ├─ Photos floues ou mal cadrées
  ├─ Photos de mauvaise qualité
  ├─ Photos de l'état sale/désorganisé
  ├─ Trop de photos identiques
  └─ Pas de titre = confusion
```

### 2. Rapide Édition des Photos de Réservation

```
Dans la table "Gérer les photos":
├─ Séquence: Drag-drop pour réorganiser
├─ Type: Cliquer pour changer (check_in → damage, etc.)
├─ Titre: Éditer directement (ex: "Coin cassé à gauche")
└─ Image: Cliquer pour voir en grand / remplacer

Aucun clic supplémentaire = Gain de temps! ⚡
```

### 3. Bouton "Copier Photos de l'Unité"

```
Utilisation:
├─ Réservation créée et photos oubliées?
│  → Cliquer le bouton!
├─ Photos de l'unité modifiées après création?
│  → Cliquer le bouton pour re-synchroniser!
└─ Besoin de réappliquer les photos initiales?
   → Cliquer le bouton!

Le bouton:
├─ Efface les photos actuelles
├─ Re-copie les DERNIÈRES photos de l'unité
└─ Marque toutes comme check_in
```

```

```

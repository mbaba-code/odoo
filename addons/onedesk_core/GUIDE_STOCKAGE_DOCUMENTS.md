## Créer un Nouveau Document

### **Étape 1: Aller au menu Stock**
```
📄 Documents → 📦 Stock de documents → Créer
```

### **Étape 2: Remplir les infos de base**
```
✏️ Titre du document:  "Contrat Locataire Dupont"
📋 Type de document:   Sélectionner parmi:
   • 📜 Contrat
   • 💰 Facture
   • 🔍 Rapport d'inspection
   • 📋 Rapport
   • 📄 Autre
```

**→ Cliquez "Enregistrer" pour créer le document vide**

---

## Stocker un PDF

### **Étape 3: Télécharger le fichier PDF**

Vous verrez cette section:
```
📁 Fichier PDF à Stocker
```

**Action:**
```
1. Cliquez sur "Télécharger un fichier"
2. Sélectionnez votre fichier PDF sur votre ordinateur
3. Attendez que le fichier soit chargé (vous verrez un aperçu)
4. ⚠️ NE CLIQUEZ PAS ENCORE SUR "Enregistrer"!
```

### **Étape 4: CLIQUER "ENREGISTRER" - C'EST IMPORTANT! ⭐**

```
AVANT de faire quoi que ce soit d'autre, vous DEVEZ cliquer:
[Enregistrer] en haut à droite du formulaire
```

**Attendez 2-3 secondes** que le document soit sauvegardé. Vous verrez un message vert confirmant la sauvegarde.

---

## Télécharger un Document

### **Une fois que le document est sauvegardé...**

Vous verrez un bouton en haut du formulaire:
```
⬇️ Télécharger
```

### **Pour télécharger:**
```
1. Cliquez sur le bouton "⬇️ Télécharger"
2. Votre navigateur téléchargera le fichier PDF
3. Vous le trouverez dans votre dossier "Téléchargements"
```

**Le fichier gardera le nom que vous avez défini** (ex: `contrat_locataire_dupont.pdf`)

## Classer et Organiser

### **Étape 5: Ajouter les informations de classification**

Après avoir uploadé et sauvegardé le PDF, vous pouvez le classifier:

```
📂 Classement & Stockage

📁 Catégorie du document:
   • 📜 Contrat
   • 💰 Facture
   • 🔍 Inspection
   • 📋 Rapport
   • ✉️ Correspondance
   • ⚖️ Conformité
   • 💳 Financier
   • ⚖️ Légal
   • ⚙️ Technique
   • 📄 Autre

🏷️ Tags/Étiquettes:
   (Tapez les tags que vous voulez, ex: "urgent", "2024", "validation")

📍 Lieu de stockage:
   (Écrivez où le document est physiquement ou logiquement stocké)
   Exemples:
   • "Dossier Principal"
   • "Archives 2024"
   • "Cloud - Google Drive"
   • "Classeur Bureau"
```

### **Étape 6: Ajouter des notes (optionnel)**

```
📝 Notes
(Toute observation ou instruction supplémentaire)

Exemple:
"Signé le 15 janvier 2024, valable 3 ans"
```

### **Étape 7: Cliquer "Enregistrer" pour finaliser**

```
[Enregistrer] - Cliquez pour sauvegarder toutes les modifications
```

## Retrouver et Revoir Vos Documents

### **Aller à la liste des documents**
```
📄 Documents → 📦 Stock de documents
```

Vous verrez **TOUS vos documents sauvegardés** dans une liste avec:
- 📄 Nom du document
- 📋 Type
- 📁 Catégorie
- 📍 Localisation
- 👤 Créé par
- 📅 Date de création

### **Cliquer sur un document pour le revoir**
```
1. Cliquez sur le nom du document dans la liste
2. Le formulaire s'ouvre avec tous les détails
3. Cliquez "⬇️ Télécharger" pour voir/télécharger le PDF
```

## Questions Fréquentes

### ❓ "Je n'arrive pas à télécharger le fichier"

**Réponse:** Assurez-vous que:
1. ✅ Vous avez cliqué "Enregistrer" après avoir uploadé le PDF
2. ✅ Le bouton "⬇️ Télécharger" est visible (pas grisé)
3. ✅ Le fichier est un PDF (pas Word, Excel, etc.)

### ❓ "Mon document a disparu après enregistrement"

**Réponse:** Il n'a pas disparu! C'est normal.
1. Allez à: 📄 Documents → 📦 Stock de documents
2. Vous verrez **TOUS vos documents sauvegardés**
3. Cherchez le vôtre dans la liste

### ❓ "Le nom du fichier est bizarre"

**Réponse:** Le nom du fichier est auto-rempli basé sur le titre du document.
- Titre: "Contrat Dupont"
- → Fichier: `contrat_dupont.pdf`
- Vous pouvez le changer dans le champ "Nom du fichier"

### ❓ "Je peux télécharger quel type de fichier?"

**Réponse:** Seuls les **PDF** sont acceptés.
- ✅ .pdf
- ❌ .docx, .xlsx, .jpg, .png (non acceptés)

Si vous avez un Word ou Excel, convertissez-le en PDF d'abord:
- Word: Fichier → Exporter en PDF
- Excel: Fichier → Exporter en PDF

### ❓ "Combien de documents puis-je stocker?"

**Réponse:** **Illimité!** Vous pouvez stocker autant de documents que vous voulez.

```
1. Créer: 📄 Documents → 📦 Stock → [Créer]

```
